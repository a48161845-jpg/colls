# Ashen Realm — Telegram-бот: текстовая RPG + квесты + idle-кликер

Один большой проект: рудник и постройки (idle + тапы), приключения с пошаговыми боями, сюжетные главы
с проверками d20, ежедневные задания, предметы 6 редкостей с заточкой, гильдии с боссом, рынок игроков,
арена с рейтингом Elo, ежедневная награда, рефералы и донат через **Telegram Stars**.
Все картинки рисуются кодом (Pillow) — никаких внешних файлов не нужно.

## Быстрый старт

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
2. Установи Python 3.11+ и зависимости:
   ```bash
   python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. `cp .env.example .env` и заполни `BOT_TOKEN` и `ADMIN_IDS` (твой Telegram ID — спроси у @userinfobot).
4. Запуск: `python -m bot`

Docker: `docker compose up -d --build`. С `DATABASE_URL` база онлайн; без него лежит в `./data`.

## Онлайн-база данных (PostgreSQL)

По умолчанию бот хранит всё в локальном файле SQLite. Чтобы база была **онлайн**, создай бесплатную базу
PostgreSQL ([Supabase](https://supabase.com), [Neon](https://neon.tech), Railway и др.), скопируй строку
подключения в `.env`:

```
DATABASE_URL=postgresql://user:password@host:5432/dbname?sslmode=require
```

Таблицы создаются сами при старте. Бот работает через пул соединений и совместим с pgbouncer (пулер Supabase).
Держи бота и базу в одном регионе: каждый запрос — сетевой, так быстрее. Перенос уже накопленных данных из SQLite:

```bash
python tools/migrate_sqlite_to_pg.py ashen_realm.sqlite3 "postgresql://user:password@host:5432/dbname"
```

Тесты на Postgres: `TEST_DATABASE_URL=postgresql://... pytest` (тестовая БД будет очищена!).

## Структура

```
bot/
  main.py, app.py        запуск, сборка Dispatcher, глобальный обработчик ошибок
  config.py              настройки из .env
  emoji.py               премиум-эмодзи: e() для текстов, p() для кнопок
  ui.py                  экран = картинка + подпись + кнопки (редактирует одно сообщение)
  data/                  ВЕСЬ контент: классы, монстры, предметы, постройки, сюжет, квесты, цены
  services/              игровая логика без Telegram (формулы, бой, идл, гильдии, рынок, арена, платежи)
  handlers/              обработчики по разделам (start, idle, adventure, story, shop, admin ...)
  keyboards/, middlewares/, utils/, db/, images/
tests/                   79 тестов: логика, гонки, сквозные сценарии с поддельным Telegram
tools/balance_sim.py     симулятор баланса боёв
assets/                  шрифты и (опционально) свои картинки: фоны и спрайты
```

## Как добавлять контент

- Монстр/локация — `bot/data/monsters.py`; предметы — `bot/data/items.py`; постройки — `bot/data/buildings.py`;
  главы сюжета — `bot/data/story.py`; задания — `bot/data/quests.py`; цены доната — `bot/data/shop.py`.
- Числа баланса — `bot/services/formulas.py` и `bot/data/balance.py`. После правок запусти
  `python tools/balance_sim.py` и посмотри процент побед и потерю здоровья.
- **Свои картинки.** Нарисованная графика процедурная (слоями гор, туманом, свечением), но это не рисунок художника.
  Настоящий арт подключается без правки кода:
  - фон раздела: `assets/images/<тема>.png` (темы: menu, idle, adventure, shop, guild, market, arena, story, ...),
    фон локации: `assets/images/loc_forest.png`, `loc_crypt`, `loc_caves`, `loc_frost`, `loc_void`, `loc_throne`;
  - монстры: `assets/sprites/monsters/<название>.png`, например `pepelnyi_volk.png` (транслит/нижний регистр:
    пробелы и знаки становятся `_`, кириллица остаётся) или по типу силуэта: `beast.png`, `skeleton.png`, `golem.png`,
    `dragon.png`, `demon.png`, `wraith.png`, `spider.png`, `knight.png`, `slime.png`, `bat.png`;
  - герои: `assets/sprites/heroes/warrior.png`, `mage.png`, `rogue.png`.
  Спрайт: PNG с прозрачным фоном, фигура смотрит влево (бот сам отразит монстра), высота от 600 px.

## Донат (Telegram Stars)

Магазин (`/shop`): кристаллы (50/250/500/1200 ⭐), подписка «Покровитель» (300/750 ⭐: +50% к идлу и др.),
набор новичка (99 ⭐). Провайдер не нужен: валюта `XTR`, токен платёжной системы пустой.
Выдача идемпотентна по `telegram_payment_charge_id` — дубль платежа не выдаст награду дважды.

- Вернуть платёж: `/refund <charge_id>` (id виден в списке платежей и в статистике админа).
- Вывод Stars делается через Telegram (Fragment) — условия и сроки проверяй в актуальной документации Telegram.
- Цены и состав паков меняются в `bot/data/shop.py`.

## Премиум-эмодзи

1. Бот может отправлять премиум-эмодзи, если у **владельца бота** (аккаунт, создавший бота) есть Telegram Premium.
   Без этого игроки увидят обычный эмодзи-заглушку — ничего не ломается.
2. Узнать ID: админ шлёт боту любое сообщение с премиум-эмодзи — бот вернёт ID.
3. Назначить: `/setemoji gold 5368324170671202286` (или `/setemoji gold` + вставить эмодзи в то же сообщение).
   Список имён — `/emojis` (63 слота: gold, crystal, hp, atk, классы, постройки, редкости ...).
   Можно также прописать в `bot/data/premium_emoji.json`. Просто пришли мне ID — я подставлю.
4. Иконки на кнопках (Bot API 9.4): `PREMIUM_BUTTONS=1` в `.env`. Ведущий эмодзи кнопки заменяется
   на премиум-иконку. Если Telegram отклонит такую кнопку, бот сам отключит иконки до перезапуска.

## Админ-панель

`/admin` — панель с вкладками (обзор, деньги, игроки, экономика): новые и активные игроки, возвращаемость, Premium,
доход в Stars по периодам с графиком, платящие и средний чек, топ плательщиков, товары, классы, уровни, золото в игре.
`/user <id или username>` — карточка игрока. `/give <id> <gold|crystals|essence|marks|potions> <n>`, `/ban`, `/unban`,
`/broadcast`, `/refund <charge_id>`, `/emojis`, `/setemoji`, `/delemoji`.

## Цены и скидки

Базовые цены лежат в `bot/data/shop.py` (Stars и кристаллы). Менять их без перезапуска можно прямо в Telegram (только админам):

- `/price` — список всех товаров с ключами, базовой и текущей ценой;
- `/price pack:gems_s 20` — поставить свою цену; `/price pack:gems_s reset` — вернуть базовую;
- `/discount packs 50 48` — скидка 50% на пакеты кристаллов на 48 часов (часы можно не указывать — тогда без срока);
- группы: `all` (всё), `stars` (за Stars), `packs`, `prem`, `cr` (траты кристаллов); можно и один ключ: `/discount prem:prem_30 30`;
- `/discount off` — снять все скидки.

В магазине игрок видит зачёркнутую старую цену и новую. Правила хранятся в БД (таблица `price_rules`) и переживают перезапуск.
Цена в счёте Stars проверяется при оплате, поэтому устаревший счёт после смены цены оплатить не получится.

## Лимиты Telegram (flood control)

Если Telegram отвечает «Too Many Requests» на смену картинки, бот не падает: экран обновляется подписью и кнопками,
а картинки не меняются, пока не истечёт срок ожидания. Если картинка на экране та же, она не пересылается вообще.

## Приглашения в гильдию

Глава гильдии нажимает «Пригласить по ID» (или пишет `/invite 123456789`). Игроку приходит сообщение с кнопками
«Принять» и «Отклонить», глава получает уведомление о решении. Приглашение живёт 3 дня, от одной гильдии
может висеть до 20. Игрок должен уже запускать бота. Свой ID каждый видит в `/profile`. Если игрока
пригласили в несколько гильдий, раздел «Гильдия» покажет все приглашения; после вступления остальные пропадают.

## Анимированные картинки

Карточки теперь живые: поднимаются искры, по кадру скользит свет, глаза монстров и героев пульсируют, по низу
стелется дымка. Telegram показывает их как зацикленные «гифки». Статичные экраны (меню, локации) кэшируются по file_id и
загружаются один раз; карточка боя делается облегчённой (меньше размер и кадров). Если нужен экономный трафик или
слабый сервер: `ANIMATED_IMAGES=0` в `.env` вернёт обычные JPEG.

## Жила рудника

Если долбить жилу без остановки, она перегревается (нагрев показан на экране рудника) и обрушивается:
удары перестают приносить золото, пока жила не восстановится сама (75 секунд) или игрок не починит её за золото.
Размеренный ритм (около одного удара в секунду) жилу не ломает. Улучшенный рудник и Premium остужают её быстрее.
Числа настраиваются в `bot/data/balance.py` (блок `VEIN_*`).

## Шрифты на картинках

Текст на картинках рисуется цепочкой шрифтов: DejaVu, затем FreeSans и GNU Unifont (почти весь Юникод: китайский,
корейский, арабский, тайский, хинди и т. д.). Эмодзи рисуются цветными из Noto Color Emoji. Ничего не вырезается: если
символа нет в основном шрифте, берётся следующий. «Красивые» шрифты (𝓗𝓮𝓵𝓵𝓸, ｆｕｌｌｗｉｄｔｈ) приводятся к обычным буквам,
невидимые знаки и стопки диакритики («зальго») чистятся, длинные имена обрезаются. Шрифты лежат в `assets/fonts/`
(лицензии в `NOTICE.txt`); свои можно положить под теми же именами.

## Рассылка

`/broadcast текст` — форматирование из сообщения сохраняется (жирный, курсив, ссылки, спойлеры, цитаты, премиум-эмодзи),
можно и писать HTML-теги руками. Фото/видео/гиф с подписью `/broadcast подпись` уходят вместе с медиа.
`/broadcast` ответом на любое сообщение копирует его как есть. Перед отправкой бот показывает предпросмотр
и просит подтвердить; блокировки бота и лимиты Telegram обрабатываются. Админу героя создавать не нужно.

## Честные оговорки

- Код проверен тестами и поддельным Telegram, но **живой запуск против настоящего Telegram у меня не проверялся**
  (в моей среде нет доступа к его серверам). Если при первом запуске что-то упадёт — пришли лог, поправлю.
- Тестировалось на aiogram 3.22 (Bot API 9.2). Иконки кнопок отправляются как дополнительное поле.
- База — SQLite (WAL), рассчитана на тысячи игроков на одном сервере. Бэкап — копируй файл базы.
- Состояния ввода (цена на рынке, название гильдии) хранятся в памяти и сбрасываются при перезапуске.
